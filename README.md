# Voice Translator 🎙️🌐

A multilingual voice translation website that records audio input, converts speech to text, translates it into a target language, and plays back the translated voice.

## 🚀 Features

* **Voice Recording:** Capture audio directly from the browser/microphone.
* **Speech-to-Text (STT):** Transcribe spoken words into text.
* **Multilingual Translation:** Translate spoken content into multiple languages.
* **Text-to-Speech (TTS):** Generate natural-sounding spoken audio output in the target language.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python (Flask / FastAPI)
* **APIs / Libraries:** SpeechRecognition, Googletrans / DeepL API, gTTS (Google Text-to-Speech)
